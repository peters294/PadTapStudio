# PadTapStudio

Pobierz aplikację: https://play.google.com/store/apps/details?id=com.kpbteam.padtapstudio

## AdMob app-ads.txt (ważne)

AdMob sprawdza plik tylko pod adresem:
`https://<hostname>/app-ads.txt`

Dla URL dewelopera z Google Play:
`https://peters294.github.io/PadTapStudio/`
hostem jest `peters294.github.io`, więc crawler szuka:
`https://peters294.github.io/app-ads.txt`

To oznacza, że sam adres `https://peters294.github.io/PadTapStudio/app-ads.txt` nie wystarczy do weryfikacji.
